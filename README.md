# AGORA

**Descubra. Explore. Aprenda.**

O AGORA começa como um aplicativo de aprendizagem por curiosidade. A pessoa pode entrar e explorar sem criar conta, sem perfil público e sem precisar compartilhar dados pessoais.

## O que existe nesta primeira versão

- Página inicial com sugestões de descobertas.
- Exploração por assuntos.
- Biblioteca com links para acervos digitais.
- Pequenas descobertas e conteúdos introdutórios.
- Biblioteca de jogos educativos em HTML.
- Tema claro/escuro.
- Estrutura PWA e cache inicial para uso offline.

## Jogos independentes

Os jogos ficam em `games/`. O aplicativo lê `games/catalog.json` para montar a biblioteca e abre cada jogo em um iframe isolado.

Consulte [games/README.md](games/README.md) para adicionar jogos e [docs/REUSO-E-LICENCAS.md](docs/REUSO-E-LICENCAS.md) para a triagem inicial de projetos e bibliotecas externas.

## Estado do projeto

Esta é uma primeira versão de interface e conteúdo estático. Ainda não há contas, sincronização de progresso, ranking compartilhado ou banco de dados. A experiência principal não exige cadastro.

## Princípios

- Curiosidade antes de obrigação.
- Acesso sem cadastro sempre que possível.
- Coletar o mínimo de dados.
- Preferir jogos próprios e projetos com licenças compatíveis.
- Respeitar direitos autorais de livros, jogos, imagens, sons, fontes e textos.
- Projetar para celular e computador.
